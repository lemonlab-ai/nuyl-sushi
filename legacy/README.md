# Legacy prototypes

此目錄只暫存三套早期原型的純原始碼，不再各自作為 Git repository：

- `server-prototype`：早期 FastAPI/MMAction2 server。
- `client-prototype`：早期 Electron/Vue client。
- `via-converter`：早期 VIA converter。

保留目的只有需求比對與 parity 檢查。新功能不得加入此目錄；等新版 core、API 與 Web 完成對照後，整個 `legacy/` 會被移除。
