# Local data boundary

This public code repository does not contain the NUYL Sushi recordings, full annotations, sensor captures, GPS data, or participant metadata.

- Private dataset repository: `lemonlab-ai/nuyl-sushi-dataset`
- Local raw inputs: `data/raw/` (ignored except placeholders)
- Local metadata override: `data/meta/video_meta.json` (ignored)
- Public schema example: `data/meta/video_meta.template.json`
- Generated outputs: `artifacts/` (ignored)

Do not copy videos or sensor files into Git without confirming consent, privacy, and Git LFS storage policy.
